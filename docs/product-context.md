# LexiFlow 产品上下文

## 产品定位

LexiFlow 是面向 Windows 的本地优先桌面翻译工具。它将划词、快速翻译、技术翻译和编程命名放在桌面工作流中，并提供本地词典、系统语音朗读、单词本、OCR、文档翻译、Profile、术语表和本地历史。

## 用户与使用场景

- 需要在 Windows 应用之间快速理解或翻译文本的用户。
- 需要处理技术文本、术语和编程命名的开发者与知识工作者。
- 希望使用本地 Ollama，或在明确知情后使用 OpenAI-compatible 服务的用户。

## 当前范围

- 托盘常驻、全局快捷键、划词提示与快速翻译窗。
- 流式翻译、句段对照、局部重译、候选译法和编程命名。
- 本地 ECDICT 查询与按需模型上下文解释。
- OCR、文本型文档分块翻译、暂停/恢复/取消及导出。
- 原文、译文和词典单词的系统语音朗读；生词保存、笔记、学习/掌握状态与本地单词本。
- Profile、术语表、自动保存设置、本地历史、收藏、隐私清除和脱敏诊断。

## 产品原则与边界

- 本地优先：本地历史和配置留在设备上；本地 Ollama 不向远程服务发送内容。
- 明确同意：使用远程 Provider 前须由用户确认；Profile 可进一步禁止远程调用。
- 隐私最小化：API Key 使用 `safeStorage`；诊断不含用户正文、译文、文档正文或密钥；OCR 临时图片在处理结束后删除。
- 进程隔离：渲染层仅通过受控 IPC 使用系统与模型能力。
- 当前仓库的交付范围是 Windows 桌面端；未维护 Web、移动端或独立服务端产品。
