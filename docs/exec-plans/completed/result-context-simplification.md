# 翻译结果上下文交互简化

状态：`completed`  
创建：2026-09-15  
最近更新：2026-09-15

## 背景

翻译结果中的句段点击和文本划选绑定在同一元素上。划选结束会触发词典查询，同时随后的点击又会锁定句段并打开局部重译，导致词典与重译界面同时出现。现有词典面板还默认展示上下文、模型解释和术语编辑，局部重译则以绝对定位浮层遮挡结果，阅读层级过于复杂。

## 目标

- 划词只打开词典，普通点击只选择句段，两种意图不再同时触发。
- 词典与局部重译互斥，并在结果下方使用一致的上下文面板呈现。
- 精简词典和局部重译的首层信息，同时保留低频能力的渐进入口。

## 范围

### 包含

- 调整 Renderer 句段选择、词典查询和局部重译状态。
- 简化 `DictionaryDrawer`、`DictionaryCard` 和 `SegmentActionPopover`。
- 更新相关样式与必要测试。

### 不包含

- 修改词典数据、模型 prompt、IPC 或主进程行为。
- 重构快速翻译弹窗和设置页。

## 方案与影响面

- 在句段组件中区分有效文本选区与普通点击，并抑制选区完成后的点击。
- 页面工作流在查词时清除句段锁定，在选中句段时关闭词典，形成单一上下文状态。
- 将重译组件从绝对定位浮层改为结果流中的面板；首层仅保留常用重译动作，其余能力渐进展开。
- 词典首层保留词头、音标、朗读、收藏、复制和核心中文释义；上下文、英文释义、词汇信息与术语编辑按需展开。
