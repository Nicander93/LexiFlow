# 划词 Logo 与系统快捷键修复

状态：`completed`
创建：2026-09-30
最近更新：2026-09-30

## 背景与目标

划词提示的窗口为 30px，悬停缩放会裁切，旧 E2E 期待 36px。启动快捷键原子注册失败会注销全部绑定，启动结果被忽略，且划词监听受其阻断。用户授权修复。

## 方案与影响面

- 统一提示窗口为 36px、按钮/图标为 32px，留边且取消悬停放大；在 Electron 页面验证尺寸与悬停，保留原确认/右键取消路径。
- HotkeyManager 按变化的绑定替换，启动保留可用项，后续失败恢复原来的可用绑定，捕获注册异常。
- 划词监听独立于快捷键注册结果。通过现有 runtime.ping 返回实际快捷键状态，在设置页显示；不新增通道或数据 schema。
- E2E 使用独立临时用户目录和空闲测试快捷键，真实调用 Windows 注册接口，另模拟失败覆盖回滚；不修改用户已运行应用。

- [x] 快捷键冲突、暂停、恢复、清空与回滚
- [x] 设置状态与指南

## 风险与回滚

不能抢占其他进程绑定，不自动修改用户快捷键。失败保留可用绑定；无数据迁移，回滚代码即可。

## 结果与遗留

启动保留可用快捷键，普通修改失败仅恢复受影响绑定。暂停、清空和恢复不干扰划词开关；设置显示实际注册状态。注册异常被转换为用户可读错误。

完整回归额外发现：IPC 不允许空快捷键，违反已有停用语义，已修复并保留类型/长度校验；清除数据恢复默认设置时快捷键冲突会报错，已允许重置保留可用项并保存默认值，普通编辑仍严格回滚。

E2E 原尺寸断言受页面动画产生的小数像素影响，改为 0.1px 精度与实际悬停边界检查，保持 36px 范围约束。真实 Windows API 探测并使用独立临时测试组合，未修改用户运行进程。测试退出使用 Playwright 自己启动的 child 的 SIGKILL，以免托盘退出拦截和原生钩子使测试 worker 悬挂。

截图：`artifacts/ui-verification/selection-tip-fixed.png` 与 `shortcut-status-fixed.png` 已查看。真实模型与 OCR 未配置而跳过；未重新打包安装版本或进行多屏 DPI 人工拖选验收。
