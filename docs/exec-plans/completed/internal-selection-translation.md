# 应用内选区翻译与中英交互

状态：`completed`
创建：2026-09-30
最近更新：2026-09-30

## 背景与目标

用户明确要求排除软件内部的系统划词 Logo，提供选中内容翻译，并限定中英互译与英文词典。保留上轮确认的正文、重译对比与草稿行为。

## 方案与影响面

- 系统划词在读取剪贴板前检查自身窗口焦点，异步读取完成后再次检查。
- 工作台输入框、原文和译文通过应用内选区工具条提供翻译；仅适合英文词典的选区提供查词。
- 独立选区翻译 IPC、请求 lane 与面板，复用 TranslationEngine、resolveModelAccess 和 ModelTaskScheduler；只发送选中文字，不写全文 Session 或历史。
- 中英自动互译复用共享语言方向判断；Profile 的风格和远程权限仍生效，选区语言方向不受全文目标设置覆盖。
- 同步共享契约、preload、注册及预览适配器，不修改本地数据 schema、架构或产品上下文。

## 风险与回滚

内部选区翻译不得覆盖正文或全文 Session，不得取消全文任务；关闭或换选区后丢弃旧事件。回滚为撤回本计划新增链路及相关 UI，无数据迁移。

## 结果与遗留

主窗口和快速翻译窗统一提供应用内选区操作。系统监听在读取前及异步结果返回后检查自身窗口焦点；检查放在鼠标释放时，避免鼠标按下瞬间焦点尚未转移导致外部首个拖选被忽略。

词典仅处理适合英语词典的选区；选区翻译强制自动中英方向但保留 Profile 的风格与远程权限。独立请求不会覆盖全文或写入历史。

实际回归发现快速翻译窗新版原文区域继承全局禁止选中文字样式，已在共享 `[data-selection-text]` 规则中修复，输入、正文及选区结果统一可选。
