# 翻译工作台交互修正

状态：`completed`
创建：2026-09-30
最近更新：2026-09-30

## 背景

用户确认直接修改代码。结果选区查询未判断词典适用性；单击句段容易误触；局部重译直接覆盖译文；编辑原文会清空成果。

## 目标与范围

- 普通文本选择与复制保持原生行为，英文选区明确点击查词，双语原文可查词。
- 句旁按钮进入调整；建议先对比、确认替换后才写入正文及历史；关闭丢弃建议，直接提供撤销。
- 编辑原文保留旧译文及待更新提示；可切换仅译文与双语对照。
- 查词失败提供针对选词的下一步；不把整句作为术语直接保存。

## 方案与影响面

调整 Renderer 工作台、共享结果组件及结果布局选择。复用现有 IPC、模型访问校验和调度；不新增数据 schema。修订及候选状态隔离未应用建议，取消并过滤旧请求事件。历史恢复保持已应用修改及撤销能力。

## 风险与回滚

风险：共享文本组件影响弹窗；异步生成完成可能晚于关闭面板或切换句段。使用请求 ID 与生命周期校验，并增加针对性回归。
回滚：撤回本计划涉及的代码及指南变更；不涉及本地数据迁移。
