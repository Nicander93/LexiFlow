# LexiFlow 执行计划

此目录只记录跨模块、持续时间较长或需要阶段性验证的工作。小型、单点且可直接验证的改动不创建计划。

- [活动计划](active/)：正在执行的计划。每次工作推进时更新任务、验证结果与阻塞项。
- [已完成计划](completed/)：已交付的计划。完成后从 `active/` 移入此处，并在计划中保留最终结果与遗留工作。
- [计划模板](_template.md)：新计划的起点；按实际任务删减无关章节，不保留空模板字段。

计划描述必须以当前代码和 `docs/` 根目录文档为依据。涉及 IPC、模型调用、本地数据或隐私时，应明确对应约束和验证方式。
