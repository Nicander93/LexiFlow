# LexiFlow 发布检查清单

每次发布都应重新执行本清单，不沿用旧版本的测试数量或历史结论。

## 自动门禁

- [ ] `pnpm test`
- [ ] `pnpm build`
- [ ] `pnpm test:e2e`
- [ ] 设置 `LEXIFLOW_E2E_MODEL` 后完成一次真实 Ollama 翻译
- [ ] 对 `release/win-unpacked/LexiFlow.exe` 执行打包产物 E2E

## 核心功能

- [ ] 主窗口、托盘、隐藏与退出行为正常
- [ ] 划词开关启停全局监听；100% / 125% / 150% / 200% 缩放下提示位于选区下方
- [ ] 快捷键冲突有明确提示；暂停后不再触发
- [ ] 新安装随 Windows 登录后台启动；关闭主窗口后快捷键仍生效，托盘退出后停止
- [ ] 快速翻译窗可关闭、固定、自动隐藏并恢复 Session
- [ ] 普通翻译、技术 Profile、命名、词典、局部重译和候选译法正常
- [ ] 中英文系统语音可朗读并停止；缺少语音包时按钮安全禁用
- [ ] 词典星标可保存生词；单词本搜索、编辑、学习状态、朗读和删除正常
- [ ] 文档任务可暂停、恢复、取消；失败分块可重试
- [ ] OCR 在单屏、双屏和不同 DPI 下框选正确，临时图片被删除

## 隐私与数据

- [ ] 首次启用远程 Provider 时拒绝确认，不保存远程确认状态
- [ ] 同意后远程调用正常；Profile 禁止远程时所有模型路径都被拦截
- [ ] API Key 不出现在 `settings.json`、日志和诊断导出中
- [ ] “清除所有本地数据”删除历史、术语表、单词本、自定义 Profile、文档任务并恢复设置
- [ ] 诊断 JSON 不包含原文、译文、文档正文或 API Key

## 安装包

- [ ] `pnpm dist:win`
- [ ] `pnpm dist:win:portable`
- [ ] 在干净用户目录验证 NSIS 安装、升级和卸载
- [ ] Portable 可启动且不依赖开发目录
- [ ] 词典数据库、图标、main ESM、preload CJS 和原生 `.node` 依赖均已打包
