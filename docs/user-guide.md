# LexiFlow 用户指南

LexiFlow 是面向 Windows 的本地优先桌面翻译工具。应用可常驻系统托盘，支持划词提示、快速翻译、技术翻译、编程命名、本地词典、语音朗读、单词本、OCR、文档翻译和本地历史。

## 首次配置

1. 打开“设置 → 模型服务”。
2. 本地模型选择 `Ollama`，确认 Base URL 和模型名称。
3. 远程模型选择 `OpenAI-compatible`，填写服务地址、模型和 API Key，并确认远程内容发送提示。
4. 点击“保存并测试连接”。开关和下拉选项立即保存，数字输入在失焦或按 Enter 后保存，模型服务与高级提示词使用明确的保存按钮。

API Key 使用 Electron `safeStorage` 加密，不写入普通设置 JSON、日志或诊断导出。

## 划词翻译

可直接在主侧栏切换划词翻译，也可在“设置 → 划词与快捷键”中配置。启用后：

1. 在其他 Windows 应用中拖动选中文字。
2. LexiFlow 会短暂读取选区，并在选区末端下方显示一个小型 Logo。
3. 点击 Logo 打开快速翻译窗。
4. 点击其他位置或等待数秒，Logo 自动消失。

默认快捷键：

| 功能 | 默认值 |
| --- | --- |
| 快速翻译 | `Ctrl+Alt+Shift+T` |
| 编程命名 | `Ctrl+Alt+Shift+N` |
| 截图 OCR | `Ctrl+Alt+Shift+S` |

新安装默认随 Windows 登录启动并隐藏到后台，因此无需先打开主窗口即可使用全局快捷键。托盘菜单可暂停所有全局快捷键。划词开关只控制选区悬浮按钮，不影响快速翻译快捷键；关闭时不会启动全局鼠标监听。选择托盘“退出”后进程不再运行，全局快捷键也会停止，直到再次启动 LexiFlow。

## 翻译与词典

- 输入单词或短语时优先查询本地 ECDICT；需要上下文翻译时点击“AI 翻译”。
- 普通、技术等翻译策略由 Profile 决定。
- 句段结果支持联动高亮、局部重译和候选译法。
- 术语表只向模型发送当前文本实际命中的启用术语。
- 翻译结果支持复制译文、原文或双语内容。
- 词典单词、普通译文、双语原文/译文和快速翻译窗支持系统语音朗读；再次点击或切换内容可停止。

## 单词本与生词

1. 输入英文单词，或在句段中选中单词打开本地词典。
2. 点击词典卡片右上角的星标，把词头、音标、释义和当前短上下文保存为生词。
3. 从工作台顶栏打开“单词本”，可搜索并筛选“学习中”“已掌握”或全部单词。
4. 在单词卡片中修改释义和笔记，点击朗读复习发音；掌握后点击“标记已掌握”，也可重新放回学习列表。

同一个词头和语言方向重复保存时会更新原条目，不会无限创建副本。单词本完全保存在本机，不会发送给模型或诊断导出。

## OCR

OCR 当前采用“选屏 → 全屏预览 → 框选文字区域 → 编辑识别结果”的流程：

- 不支持直接在多个屏幕上一次性原生框选。
- OCR 临时图片在识别完成或失败后删除。
- 识别结果不会自动覆盖翻译页原文，确认后再送入翻译。

## 文档翻译

支持 TXT、Markdown、SRT、带文本层的 PDF，以及常见代码与配置文件。文档任务按单并发队列执行，可暂停、恢复、取消和导出。

扫描版 PDF 不包含可提取文本层，应先使用 OCR。

## 本地数据与隐私

应用数据通常位于 `%APPDATA%/LexiFlow`，包括设置、历史、术语表、单词本、Profile 和文档任务。

- 本地 Ollama 不会把内容发送到远程服务。
- OpenAI-compatible Provider 会把待处理内容发送到所配置的服务。
- Profile 可禁止远程模型。
- “清除所有本地数据”会恢复设置并删除历史、术语表、单词本、自定义 Profile 和文档任务。
- 诊断导出只包含环境与匿名错误计数。
